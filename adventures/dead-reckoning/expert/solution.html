What Was Fixed

The expert level required end-to-end distributed tracing across an asynchronous event-driven pipeline, and verified that commissioned vessels report the correct cargo. Two critical fixes make the full voyage visible in Jaeger while ensuring manifest accuracy.

1
Traceparent embedded in code repo commit message The scaffolder template now includes gitCommitMessage with Traceparent: ${{ steps['trace-start'].output.traceparent }} on the code repository push. The Argo Events Sensor extracts this trailer and threads it into the workflow so CI and Argo CD spans join the commission trace.
2
Service reads PROVISIONS env var (not CARGO) The generated Go service in main.go now correctly reads os.Getenv("PROVISIONS") instead of "CARGO", matching what the deployment manifest declares and allowing the vessel to report accurate commissioned cargo.
3
Backstage trace opens with captain's form time The dr:trace-start action uses enterStart to back-date the root span, so the trace begins with the captain filling the commission form, not the scaffolder's first action.
4
Trace spans reconstructed from task logs The dr:trace-finish action reads the scaffolder's task log, emits one span per work step under the root, and closes the trace. This keeps template steps ordinary untraced actions while still capturing their timing.
